SMART DIGITAL EXPENSE TRACKER WITH BUDGET PREDICTION

FILES
01_Smart_Digital_Expense_Tracker.cpp - Complete C++ source code.
02_Project_Report.txt - Objective, modules, algorithm, run steps, sample and conclusion.

RUNNING
Compile with a C++11-or-later compiler, then run the executable.
Register a user, log in, set a budget, and add expenses.

The program creates users.txt and per-user expense/budget text files when used.
Keep those files in the same folder as the program to preserve data.
This is a simple educational example; passwords are stored as plain text.
